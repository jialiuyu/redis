### SVE2硬件加速预期

#### SVE2向量化收益

ARM SVE2特性：
- **向量长度**: 256-2048 bits (硬件可配置)
- **并行度**: 8-64个float32元素
- **Gather指令**: 单指令多数据加载

假设SVE2向量长度为512 bits (16个float32)：

```
标量实现:
- 每次memcpy: 300个float (1200 bytes)
- 操作数: 300次load + 300次store = 600次内存操作

SVE2实现:
- 每次gather: 16个float并行
- 操作数: 300/16 = 19次向量操作
- 加速比: 600 / (19*2) ≈ 15.8x
```

## 性能瓶颈分析

### 当前瓶颈（标量实现）

1. **内存拷贝**: memcpy占用约67%的时间
   - 300个float的顺序拷贝
   - 无法利用SIMD并行

2. **批聚合延迟**: 161 μs等待时间
   - 为了达到3000 requests/batch
   - 可以通过动态批大小优化

3. **线程扩展性**: 16线程后收益递减
   - 内存带宽限制
   - 缓存竞争

### SVE2消除的瓶颈

✅ **向量化gather**: 16x并行加载
✅ **减少内存操作**: 从600次降到38次
✅ **更好的缓存利用**: 向量预取
✅ **降低延迟**: 从0.30 μs到0.019 μs

### 性能优化

1. **NUMA优化**: 
   - 将embedding表分配到本地NUMA节点
   - 线程绑定到特定核心

2. **预取优化**:
   - 使用SVE2预取指令
   - 提前加载下一批数据

3. **批大小调优**:
   - 根据延迟要求动态调整
   - 平衡吞吐量和延迟

4. **多级缓存**:
   - L1/L2缓存热点embedding
   - 减少DRAM访问
